# Phase 3 metadata report

## Scope

This report describes the annotation files added after Phase 2 and their
relationship to the fixed 139,255-neuron simulator universe. Counts and hashes
are generated by `tools/prepare_phase3_metadata.py` and saved in
`data/processed/phase3_metadata.json`.

## Files

| File | Rows | Unique root IDs | Duplicate ID rows | Schema |
|---|---:|---:|---:|---|
| `classification.csv.gz` | 139,255 | 139,255 | 0 | `root_id, flow, super_class, class, sub_class, hemilineage, side, nerve` |
| `consolidated_cell_types.csv.gz` | 138,327 | 138,327 | 0 | `root_id, primary_type, additional_type(s)` |
| `visual_neuron_types.csv.gz` | 95,079 | 95,079 | 0 | `root_id, type, family, subsystem, category, side` |

`classification.csv.gz` exactly covers the simulator metadata universe: no
missing and no extra root IDs. Consolidated cell types are a strict subset:
928 simulator neurons have no row, and there are no extra IDs. The visual table
is also a subset, with no extra IDs.

SHA-256 values are recorded in `data/processed/phase3_metadata.json`. The two
new exports came from the official FAFB v783 Codex static-data location.

## Relevant annotations

**DATA FACT:** classification contains 19,300 `afferent` and 1,491 `efferent`
flow annotations. Superclasses include 16,938 `sensory`, 1,305 `descending`,
110 `motor`, and 77,873 `optic` neurons. It contains 11,153
`sub_class=photo_receptor` rows.

**DATA FACT:** the visual table contains 9,706 `family=Photo Receptors` rows.
Every one of these also has `classification.sub_class=photo_receptor`; all are
in the simulator universe. The intersection has 4,955 left and 4,751 right
annotations.

**BIOLOGICAL INTERPRETATION:** the agreement of two annotation layers supports
using that intersection as a photoreceptor input candidate population. It does
not imply the artificial five-sector sensor recreates retinal sampling.

**DATA FACT:** 1,305 neurons have explicit
`classification.super_class=descending`: 647 left, 650 right, and 8 with
center/blank side. All are in the simulator universe.

**BIOLOGICAL INTERPRETATION:** `descending` is a defensible downstream/output
observation population. It does not specify muscles or artificial actions.

Official context: [Codex FAQ](https://codex.flywire.ai/faq) describes cell-type
consolidation and hierarchical fields; [About FlyWire](https://codex.flywire.ai/about_flywire)
credits hierarchical annotations and explains their sources.
