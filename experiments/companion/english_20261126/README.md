These are controlled development fixtures, not campaign evaluation scores.
The original failing attempts, raw supervisor summaries and successful fresh
attempts are retained separately. `english_record_3/audit.json` explicitly
explains its post-result supervisor misclassification without rewriting the
original summary. `english_record_4` passed the corrected supervisor as well
as native collection and delivery.

Each audit counts acknowledged resource actions, preserves native task/pickup
receipts and lists original artifact paths and SHA256 hashes. Raw native and
bridge logs are included. The fixture's deterministic tree and starting pose,
synthetic chat, engineered return navigation and zero-impulse handoff remain
separate from neural resource action selection.

All successful resource requests began without logs or crafted items. The
wooden pickaxe was crafted in Minecraft before being delivered into the
requester's inventory. The failed three-log request remains failed: three
breaks, two NPC pickups, no recipient pickup, 120 actions.

Milestone MP4s remain outside Git at the absolute paths in the corresponding
audit. Both successful milestone files passed full FFmpeg decoding; their
Minecraft-only source frames matched independent game screenshots. Earlier
failed captures remain in their original local output paths.

`english_language_release.txt` also tests count-preserving replanning and
